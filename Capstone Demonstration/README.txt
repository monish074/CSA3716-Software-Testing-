SENTINELQA — SELF-HEALING AUTOMATED TESTING & VULNERABILITY DETECTION PLATFORM

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html (or right-click -> Open with Chrome).
4. Register a new account, then sign in.
5. Add a project, run a test scan, load sample vulnerabilities, and simulate a healing event.

PAGES
- index.html: Login
- register.html: Registration
- dashboard.html: Overview dashboard
- projects.html: Project management
- scans.html: Simulated automated test runs
- vulnerabilities.html: Vulnerability register and remediation tracking
- healing.html: Self-healing simulation and recovery timeline
- reports.html: Reports and audit trail
- settings.html: Profile, JSON backup, and reset

DATA STORAGE
The website uses browser localStorage. Registration, profile, projects, scan history, findings, healing events, and activity logs persist in the same browser on the same device. Clearing browser site data will remove this demo data. Use Settings -> Download workspace backup to export the records.

IMPORTANT
This capstone prototype demonstrates the workflow and UI. Scans and vulnerability findings are simulated; it does not actually crawl websites, execute browser automation, or perform penetration testing. Do not enter real passwords or sensitive information. Production deployment requires a secure backend, authentication, authorization, encrypted transport, and a real test runner/security scanner.
